## Planned Runbook Flow

1. Identify the affected user and course activity.
2. Identify the environment: CVD, Windows, macOS, or Linux.
3. Identify whether the problem involves access, the course IDE, GitHub, a repository, Python execution, or student code.
4. Confirm the expected IT 140 environment where appropriate.
5. Run or interpret the supported verification procedure.
6. Review relevant exit codes and logs.
7. Apply only documented safe remediation.
8. Determine whether the issue belongs to Service Desk, faculty, LSS, or another support path.
9. Escalate unresolved technical issues with the required evidence package.
