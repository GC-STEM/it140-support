# IT 140 Advisors | Common Scenarios

Use these examples for quick advisor guidance.

## "I Can't Get Codio to Open"

This is a technical access problem.

**Route:** IT Service Desk.

If the student also has an academic concern because the problem affected coursework, the advisor can address the broader concern while faculty handles course-specific academic decisions.

## "I Can't Install Python or VS Code"

The student does not need to keep fighting with a local installation if the CVD is available.

**Route:** IT Service Desk for the technical issue.

**Advisor message:** The CVD is the course reference environment and can normally be used instead of a local installation.

## "I Only Have a Chromebook / Tablet"

Do not immediately conclude that the student cannot complete IT 140.

The student may be able to use the browser-accessed CVD.

**Route:** IT Service Desk for device/access compatibility questions.

See [Technology Context](technology-context.md#chromebooks-tablets-and-other-devices).

## "My Program Doesn't Work"

Ask one routing question:

> "Can Python run, but your program gives the wrong result—or will the course tools not run at all?"

- Course tools/Python will not run → **IT Service Desk**.
- Python runs, but the student's program is wrong → **faculty or LSS**.

## "I Don't Understand Loops / Functions / Dictionaries"

This is a programming-learning need.

**Route:** instructor and/or LSS.

The advisor does not need to explain the programming concept.

## "I Don't Know What the Assignment Is Asking"

**Route:** current D2L Brightspace Guidelines and Rubric and the instructor.

LSS may help with the programming concepts after the assignment requirement is clear.

## "I Don't Understand My Grade"

**Route:** instructor.

The advisor should not reinterpret the rubric or instructor feedback.

## "GitHub Deleted My Assignment"

Do not assume the work is actually deleted.

The student may be:

- signed into the wrong GitHub account;
- looking at the public GC-STEM template;
- looking at a different local folder; or
- missing only the local clone.

**Route:** IT Service Desk for repository/account recovery.

Do not advise the student to create a new repository or delete anything.

## "I Reset Codio and My Work Is Gone"

A CVD reset can remove the local configured environment.

If the student's work was pushed to their private GitHub repository, it may be recoverable by cloning that repository again.

**Route:** IT Service Desk for technical/repository recovery.

## "I'm Repeating IT 140. Can I Use My Old Repository?"

Students repeating IT 140 should use repositories created from the **current course templates** for the new attempt.

They should not use the old assignment/project repository as the active repository for the current course attempt.

For repository-specific help, route to the course workflow/technical support path.

## "I'm Overwhelmed and Thinking About Changing My Schedule"

This is an advising concern, but identify whether a fixable course-specific barrier is contributing.

Ask whether the main issue is:

- technical access → Service Desk;
- programming understanding → faculty/LSS;
- assignment/grading → faculty; or
- broader academic planning/workload → advisor.

The student may need more than one path at the same time.

## "I've Already Contacted Someone and I'm Still Stuck"

Ask:

1. Who did the student contact?
2. What part of the problem was addressed?
3. What remains unresolved?

Then route the **remaining problem**, not the original description.

Example:

> Service Desk fixed VS Code, but the student still does not understand the program.

The remaining issue is now a **learning problem** → faculty/LSS.

## "Several Students Are Reporting the Same Technical Issue"

Do not try to diagnose it.

Encourage reporting through the technical support/course path and preserve the common symptom or affected course resource.

A repeated issue may be a course/platform problem rather than several independent student mistakes.
