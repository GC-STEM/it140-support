# IT 140 Academic Advisor Support Guide

This guide is the starting point for **Academic Advisors** supporting students who are enrolled in, preparing for, or experiencing difficulty in **IT 140 - Introduction to Scripting**.

Advisors often have a longer relationship with a student than any individual course instructor, so a student may contact their advisor first when something goes wrong in IT 140.

You do **not** need to be a programmer or technical-support specialist to help effectively.

> [!IMPORTANT]
> The advisor role is to **recognize the type of problem, help the student understand the next step, and connect the student to the right support resource**.
>
> Advisors are not expected to troubleshoot Git, Python, VS Code, GitHub, or IT 140 course automation.

This guide is written for both STEM and non-STEM advisors. IT 140 serves as an introductory programming course for STEM students and may also be taken by students from other academic areas as a general-education elective.

## The Most Important Advisor Distinction

When a student says:

> "IT 140 isn't working."

the problem may mean very different things.

### Technical Problem

Examples:

- the CVD will not open;
- VS Code will not start;
- Python cannot run;
- GitHub authentication fails; or
- the student cannot create or clone the repository.

**Route:** IT Service Desk.

### Learning Problem

Examples:

- the student does not understand a programming concept;
- the student's code runs but gives the wrong result;
- the student needs help debugging; or
- the student needs more practice.

**Route:** Faculty and/or LSS.

### Assignment or Grading Problem

Examples:

- what must be submitted;
- whether work meets the rubric;
- a grade;
- instructor feedback; or
- an assignment deadline.

**Route:** Faculty.

### Academic or Persistence Concern

Examples:

- the student is overwhelmed;
- the student is considering changing their academic plan;
- the student is concerned about course sequencing;
- the student is balancing the course with broader academic or life circumstances.

**Route:** Advisor, using normal advising processes, while connecting course-specific subproblems to the appropriate support role.

## Key Course Facts for Advisors

You do not need to memorize technical details. These high-level facts are enough for most advisor conversations:

- IT 140 is an **eight-week introductory Python programming course**.
- Students may begin with **no previous programming experience**.
- Students learn through D2L Brightspace, zyBooks, the course development environment, and GitHub-based course resources.
- **D2L Brightspace is authoritative for graded assignment requirements and submissions.**
- The **Codio Virtual Desktop (CVD)** is the IT 140 reference development environment.
- A supported local installation is optional; a student can normally use the CVD instead.
- GitHub is part of the student's development workflow, but **GitHub is not the assignment-submission system**.
- Faculty handle assignment interpretation and grading.
- LSS provide optional programming learning support.
- The IT Service Desk handles technical environment and access problems.

For more context, see [IT 140 Course Overview](../shared/course-overview.md).
